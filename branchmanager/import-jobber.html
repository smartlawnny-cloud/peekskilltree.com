Import Jobber Data

Transfer quotes, jobs, and payments from Jobber JSON files into Branch Manager (localStorage + Supabase if connected).

Note: This tool reads from localStorage. Open BM first, log in, then come back to this page in the same browser window.

📋 Quotes + Line Items 437 quotes · 1,227 line items

Merges line items (service, qty, rate, photos) into existing BM quotes matched by quote number. Creates quotes that don't exist yet.

🔧 Jobs + Line Items 259 jobs · 565 line items

Imports jobs matched by job number. Creates new jobs for unmatched numbers. Links to existing clients by name.

💰 Payments 364 payments

Imports payment records (amount, date, method) and links to clients by name. Stored in bm-payments-[clientId] keys.
